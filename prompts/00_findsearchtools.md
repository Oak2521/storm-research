# 按需发现检索能力

仅在当前来源路径不足或工具未知时读本文件。优先使用会话中真实可调用的工具，选择与主题匹配的官方、学术或通用检索渠道。

1. 从当前工具目录的名称与描述筛选本次需要的能力，不扫描用户主目录或无关项目。
2. 找不到合适工具时，使用宿主提供的工具搜索。已安装的专用平台 Skill 优先于自行拼接抓取链。
3. 只加载选定工具/Skill 的使用说明；调用成功且取得实质内容后才能称该路径可用。
4. 工具失败时按错误类型选择一个合理替代；登录、付费或访问控制需要对应授权，不以换工具绕过。
5. 没有可用来源时，交付已确认部分和缺口，不用列出所有潜在工具来代替研究。

通常只向用户报告实际采用的来源及重要访问限制。原始工具目录与命令输出不属于默认交付物。
