# 湖岸橡树 Oak by Lake · 网站信息架构（Information Architecture）

## 建站蓝图 · 深结构 / 窄门面 / 单漏斗

> **这张图回答什么**：完整蓝图怎么落到网站结构上，同时不让"一个人 + AI"被一座大教堂拖垮。核心原则一句话——**结构做完整，门面只开滩头堡，营销死磕单漏斗**；**展示 ≠ 在售 ≠ 可交付**。
>
> 因此每一个页面都带一个**状态标签**，决定它现在"建到什么程度、挂不挂购买/咨询按钮"。

---

## 一、状态图例（每个页面的三种状态）

| 标记 | 状态 | 含义 | 是否挂"购买/咨询"按钮 |
|---|---|---|---|
| 🟢 | **在售且可交付** | 第 1 年上线、一人+AI 交付得了、单漏斗核心 | 是（主转化）|
| 🟡 | **邻居门 · 轻落地页** | 展示 + 留咨询入口，但不是完整在售产品 | 只留"咨询/预约"，不承诺完整交付 |
| ⚪ | **愿景骨架槽位** | 信息架构里预留位置、结构完整，但暂不建成在售页 | 否（不挂购买按钮，最多"了解方向/敬请期待"）|

> 关键纪律：⚪ 页面**可以在站点地图和"关于/蓝图"叙事里出现**（让站点显得完整、正规、有野心），但**不给它购买按钮**——避免有人来问、你（一人）交付不了而砸口碑。

## 三、读者动线漏斗（三段旅程 · 价格永远是终点）

```text
① 信息与态度  ——— 先获得信息、感到温度
   首页（态度样板）
     → 五入口地图（先承接担忧）
     → 免费前门「还没想好也没关系」（免费、不催促）
     → 凭什么信你·信任页（先说出怀疑，再逐条亮可核验证据）
                         │
                         ▼
② 看见能做成什么 ——— 看见自己能做成的事
   对应服务页（按读者目的领头）
     每页固定顺序（见第四节）：
     承接担忧 → 能做成什么（结果+案例+样品）→ 正规可查证证据 → 价格
                         │
                         ▼
③ 评估成本 ——— 最后才谈钱
   该页最后一屏：交付内容 · 周期 · 价格与边界
     → 咨询 / 预约（CTA 读者口吻领头）
```

### 单漏斗高亮（一年跑道押注的主转化路径）

> **入口（书作杠杆客群）→ 信任页 → 出版服务·「信用之书」→ 焊入书后 Echo → 成本/成交**

这条 🟢 主路径是营销与在售的唯一焦点；其余板块要么服务这条路径（文脉=引流、内容层=信任前奏、服务案例=证据），要么是 ⚪ 暂不导流的骨架。

## 四、每个服务页的统一信息架构顺序（页面顺序约定卡）

```text
┌─────────────────────────────────────────────┐
│  ①承接担忧    "你是不是在担心…"                │
│  ②能做成什么  结果 + 情感承诺 + 案例/样品      │
│  ③可查证证据  正规身份 + 诚实边界说明          │
│  ④价格        交付/周期/价格（永远最后一屏）   │
└─────────────────────────────────────────────┘
```

修法落到页面的三处硬标注：
- **学术出版页**：③里含"国内认可度现状"诚实告知（认定权在用人单位、海外专著多为补充）。
- **真实写作档案页**：叫"档案/声明备案"，不叫"认证"；卖过程留痕与安心，不卖检测报告。
- **信任页**：把可核验资质集中一处 + **预收款分段解锁 + 停业保障条款** + "上架≠销量/WorldCat 诚实说明"。

## 五、建站分期（按状态与三至五年节奏）

| 阶段 | 建成并在售 🟢 | 邻居门 🟡 | 只留骨架 ⚪ |
|---|---|---|---|
| **第 1 年** | 首页+五入口+免费前门+信任页；出版服务「信用之书」；真实写作档案；书后 Entry/Echo；选题诊断；微型书；服务案例；文脉季刊/聚合；未读物档案首批；湖岸索引 6+1 初版 | 家族记忆门、机构门、书稿孵化、湖岸出品、资料整理 | 汇流共创、书后 Archive/Companion、湖岸索引 GEO、Book as Service 全量 |
| **第 2–3 年** | 书稿孵化转在售、样章共创、书后 Archive、家族记忆入门路径、内容层稳定产出、湖岸索引词条补齐 | 机构项目、完整共创（by application 展示）| 完整书稿共创大单、对外认证、版权业务 |
| **第 4–5 年** | 书后 Companion、机构项目、授权国内简体版、版权/Rights Lab | — | — |

> 分期原则：🟢 先建高毛利可重复 + 单漏斗核心；🟡 用最轻的落地页占住"邻居门"保留可能性；⚪ 只在站点结构里留槽位，见钱之后再逐格填。

## 六、一页速记（把整张图压成六句话）

1. **主导航 7 项**保留完整蓝图，但每页带状态标签。
2. **🟢 在售**只押"信用之书"单漏斗 + 支撑它的信任/案例/文脉/内容前奏。
3. **🟡 邻居门**用轻落地页占位（家族记忆/机构/孵化），只留咨询不承诺完整交付。
4. **⚪ 骨架槽位**（汇流共创/长程陪跑/书后高阶/GEO冲刺/对外认证/版权）进站点结构、**不挂购买按钮**。
5. **读者动线**永远"信息与态度 → 能做成什么 → 成本"，价格在最后一屏。
6. **修法上墙**：WorldCat 诚实表述、学术页认可度告知、真实写作档案（非认证）、信任页含预收款保护——每一处诚实都是信任资产。
